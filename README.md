# 3D Print Rig toolhead models

Pinned native Trinity / Crossbow references used by [3D Print Rig](https://psych0h3ad.github.io/3d-print-rig/). Ten source-assembled heads include Sherpa Mini R2, source fans, hotends and Beacon RevD. The original Crossbow / Sherpa Mini R2 Short / Dragon ACE Volcano / Beacon RevD Normal combination is also an alpha viewer preview on standard Trident 250/300/350. Mounting and clearance validation is incomplete.

Printed parts, Crossbow CNC, Annex geometry and manufacturer bodies retain their separate terms and authors. See [the notice](site/NOTICE.txt), pinned source records in each model and [editable native solids and assembly transforms](https://psych0h3ad.github.io/3d-print-rig-toolhead-models/trinity-native-source.zip).

The alpha reference has its own [current native solids, assembly transforms and printed derivative notices](https://psych0h3ad.github.io/3d-print-rig-toolhead-models/trinity-alpha3-native-source.zip). Large immutable model files are stored in checksum-pinned pieces and reassembled by the Pages builder; the served model retains its original bytes.
